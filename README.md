# 🚀 Build a $10,000 Premium Website with Google Antigravity (No Code, 100% Free)

## Overview
Learn how to build and clone a premium, modern landing page using nothing but AI prompts, without writing a single line of code. This project walks you through the complete workflow: collecting design references from a real website, downloading its images and videos, converting a static image into an animated video with AI, and generating a polished multi-section website with Google Antigravity inside VS Code. The result is built with pure HTML, CSS, and vanilla JavaScript, with no frameworks, no npm, and no backend.

## Key Features
- **Fully AI-Generated Website** – Every section is generated from step-by-step prompts, with zero manual coding
- **Navigation Bar & Hero Section** – Glowing hero with a headline, subtext, and two call-to-action buttons with hover effects
- **Video Modal Player** – Click the app preview to open a video that can skip forward, skip backward, and be closed
- **Multi-Section Landing Page** – Hero, Research and Reading, Local Files (Privacy), About, and Footer sections
- **Animated World Graphic** – A static globe image converted into a smooth, horizontally moving video using AI
- **Premium Dark Theme** – Deep navy background with purple glow effects, rounded buttons, and pill-shaped tags
- **Footer with Newsletter** – Link columns, social icons, an email subscribe field, and legal links
- **Design Reference Workflow** – Screenshots of each section guide the AI to match the layout accurately
- **Reusable `context.md` Rules File** – Golden rules, architecture, and design system that keep every prompt consistent
- **Free Asset Collection** – Download images and videos directly from the source site, or generate them with AI
- **Step-by-Step Prompting** – Build section by section instead of generating the whole project at once
- **Live Preview** – Test instantly in the browser using the Live Server extension
- **No Framework Required** – Only three files: `index.html`, `style.css`, and `script.js`
- **No Backend or Packages Required** – No npm, Python, or external dependencies needed

## Technologies Used
- **Google Antigravity** – AI coding agent used as a VS Code extension to generate the entire website
- **VS Code** – Code editor used to organize the project and review AI-generated changes
- **Live Server** – VS Code extension for instant live preview in the browser
- **HTML5** – Semantic structure for all sections of the landing page
- **CSS3** – Custom dark theme, glow effects, layout, hover effects, and animations
- **JavaScript (ES6+)** – Video modal controls and interactive behavior
- **Browser DevTools (Inspect Element)** – Extracting image and video sources from a live website
- **Snipping Tool** – Capturing design reference screenshots and fallback assets
- **Manus** – Generating images and converting a static image into a video
- **FFmpeg** – Used by the AI agent to capture exact frames from videos for design accuracy
- **Markdown (`context.md`)** – Project rules and instructions that guide the AI

## Project Structure
```
project-folder/
├── images/                  # Images downloaded or generated for the website
├── videos/                  # Videos used on each page
├── page-design-reference/   # Screenshots of each section (first-page, second-page, ...)
├── context.md               # Rules, architecture, and design system for the AI
├── index.html
├── style.css
└── script.js
```

## Learning Outcomes
- **Website Cloning with AI** – Recreate a real website's design using prompts alone
- **Asset Extraction** – Download videos and images from any website using Inspect Element
- **Direct Video URL Trick** – Open a video source link on the site's domain and download it
- **Screenshot Fallback** – Capture assets with the Snipping Tool when downloads fail
- **Design References** – Prepare section screenshots so the AI understands the exact layout
- **Project Organization** – Structure `images`, `videos`, and `page-design-reference` folders with clear naming
- **Image-to-Video with AI** – Turn a static image into a smooth, looping video using a prompt
- **Writing AI Rules** – Use a `context.md` file to define architecture, design system, and golden rules
- **Step-by-Step Prompting** – Build the navigation and hero first, then each section one by one
- **Chaining Prompts** – Run multiple prompts in sequence using "then" to build several sections at once
- **Agent Permissions** – Understand and approve the permissions the AI agent requests
- **BTW Command** – Pass extra instructions without interrupting the main conversation
- **Reviewing AI Changes** – Inspect inserted lines and accept or reject generated code
- **Live Preview Workflow** – Use Live Server's "Go Live" to test and compare results in the browser
- **Vanilla Web Stack** – Build a premium UI with only HTML, CSS, and JavaScript
- **Real-World Application** – Create a portfolio-ready landing page workflow you can reuse for any website

## 🚀 How to Run
1. Download or clone this repository
2. Open the project folder in **VS Code**
3. Install the **Live Server** extension
4. Open `index.html` and click **Go Live** in the bottom bar
5. The landing page opens in your browser
